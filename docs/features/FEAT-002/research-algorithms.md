# FEAT-002 算法调研：可用于选号推荐的数学方法

> 结论先行：选号每期开奖相互独立，任何基于历史数据的排序、打分、机器学习都不能提高单注期望。FEAT-002 的算法定位是「号码画像 + 组合优化 + 覆盖设计 + 可验证回测」，不是「预测中奖」。
> 调研日期：2026-11-23。

## 1. 基础概率与期望

### 1.1 头奖概率

- 红蓝玩法：`C(33,6) × 16 = 1,107,568 × 16 = 17,721,088`，头奖概率约 1/1772 万。
- 前后玩法：`C(35,5) × C(12,2) = 324,632 × 66 = 21,425,712`，头奖概率约 1/2143 万。

### 1.2 单号出现概率与期望遗漏

单期内某个号码被选中的概率（无放回抽样）：

- 红蓝玩法红球：`6/33 = 18.18%`，期望遗漏 `1/p ≈ 5.5` 期；蓝球 `1/16 = 6.25%`，期望遗漏 16 期。
- 前后玩法前区：`5/35 = 14.29%`，期望遗漏 7 期；后区 `2/12 = 16.67%`，期望遗漏 6 期。

「某号很久没出，下一期该出了」是赌徒谬误：条件概率不因历史遗漏而改变。遗漏值只能作为展示指标，不能作为「必出」依据。

### 1.3 期望收益

官方返奖比例约 51%（红蓝玩法规则第十四条：51% 计提奖金），长期期望为负。任何选号方法只改变号码分布，不改变负期望。

## 2. 方法清单与评价

| 方法 | 数学基础 | 能做什么 | 局限 | FEAT-002 角色 |
|---|---|---|---|---|
| 均匀随机 | 等概率组合 | 公平基线、避免人为偏差 | 不做任何筛选 | 基线 & 预设 |
| 频率/冷热 | 二项/多项分布、z 分数、卡方检验 | 描述历史频率、发现偏离 | 不代表下期概率；小样本噪声大 | 展示 + 特征 |
| 遗漏值 | 几何分布、期望遗漏 | 展示「多久未出」、分层 | 赌徒谬误 | 展示 + 特征 |
| 贝叶斯平滑 | Beta-Binomial / Dirichlet | 稳定估计单号概率、给不确定性 | 无预测力，只做收缩估计 | 特征 |
| 马尔可夫链 | 转移矩阵、卡方独立性检验 | 检验「上期出→下期出」是否有依赖 | iid 下转移≈边际；易过拟合 | 研究/回测 |
| 时间序列/ML | ARIMA、LSTM、Transformer、XGBoost | 序列拟合、非线性特征 | 样本少、非平稳、几乎必然过拟合 | FEAT-003 评估 |
| 遗传算法 | 组合优化、适应度函数 | 在约束下搜索「好看」的组合 | 优化的是自定义评分，不是中奖概率 | 组合搜索 |
| 蒙特卡洛 | 随机模拟、置信区间 | 估计覆盖/命中分布、验证策略 | 不产生预测力 | 回测/评估 |
| 覆盖设计/旋转矩阵 | 组合设计、集合覆盖 | 用较少注数保证「池中命中 k 个」时覆盖若干奖级 | 需更多注数；保证的是覆盖不是中奖 | 多注推荐 |
| 集成/融合 | 加权平均、排序融合 | 降低单策略波动、稳定输出 | 无信号时不会提升期望 | 推荐默认 |
| 信息熵 | Shannon 熵、分布散度 | 衡量号码分布多样性 | 不预测 | 约束/展示 |

## 3. 各方法的可落地公式

### 3.1 频率与 z 分数

窗口 `N` 期，号码 `i` 出现 `c_i` 次，单期出现概率 `p = base/range`：

```text
期望次数 E_i = N × p
标准差 σ_i = sqrt(N × p × (1 - p))
z_i = (c_i - E_i) / σ_i
```

`z_i > 0` 偏热，`z_i < 0` 偏冷。z 分数只描述历史偏离，不是下期概率。

### 3.2 卡方均匀性检验

```text
χ² = Σ (c_i - E_i)² / E_i
自由度 df = range - 1
```

用 χ² 分布计算 p 值。p 值大表示「与均匀分布无显著差异」；不能据此选号，只能提示「历史分布是否异常」。

### 3.3 遗漏值

当前遗漏 `o_i` = 距最近一次出现的期数；最大遗漏 `max_o_i`；平均遗漏 `avg_o_i`。

若把单号出现近似为独立伯努利试验：

```text
P(遗漏 = k) = (1 - p)^(k-1) × p
期望遗漏 = 1/p
遗漏比 = o_i / (1/p)
```

遗漏比 > 1 表示「比期望更久未出」，仅用于分层展示。

### 3.4 贝叶斯平滑（Beta-Binomial）

对单号出现概率设先验 `Beta(α, β)`，观测 `c_i` 次出现、`N - c_i` 次未出现：

```text
后验 = Beta(α + c_i, β + N - c_i)
后验均值 = (α + c_i) / (α + β + N)
```

默认 `α = β = 1`（均匀先验）。小样本时向 0.5 收缩，避免「出现 1 次就 100%」的极端估计。可输出 95% 可信区间宽度作为不确定性。

### 3.5 马尔可夫链

对单号建立两状态链：出现（1）/未出现（0），估计转移概率 `P(1|1)`、`P(1|0)`。若数据 iid，则两者都应接近边际概率 `p`。用卡方独立性检验判断是否存在显著转移依赖；即使显著，也需 walk-forward 验证是否稳定，不能直接用于预测。

### 3.6 序列模型（LSTM/Transformer/XGBoost）

输入最近 `W` 期号码的 multi-hot 向量，输出下一期每个号码的概率/分数。风险：

- 样本量小（几百到几千期），参数量大，极易过拟合。
- 开奖 iid，不存在稳定可学习信号；验证集表现通常回到随机基线。
- 需要严格 walk-forward、固定随机种子、与随机基线对比，不能只看训练集命中。

参考「项目 N（全链路基准实验）」的公开实验记录：其 LSTM/Transformer/XGBoost 在 60 期隔离验证中未优于均匀概率基线。FEAT-002 不落地深度模型，FEAT-003 若要尝试，必须沿用同一套回测门槛。

### 3.7 遗传算法

把一注号码编码为染色体，适应度 = 约束满足度 + 特征得分 + 多样性惩罚。交叉/变异后保留高分个体。它优化的是「我们定义的评分函数」，不是中奖概率；适合在大量约束下搜索组合，需防止评分过拟合。

### 3.8 蒙特卡洛与回测

对策略重复采样/滚动生成，统计：

```text
命中率 = 命中注数 / 总注数
投入 = 注数 × 单价
回报 = Σ 各注奖金（按奖级表）
ROI = (回报 - 投入) / 投入
```

用 Wilson 区间估计命中率置信区间：

```text
p̂ ± z × sqrt(p̂(1-p̂)/n)   （近似）
```

Wilson 区间在小样本/极端比例下更稳健。回测必须 walk-forward：评估第 t 期时只能使用 t 之前的数据。

### 3.9 覆盖设计与旋转矩阵

设选号池有 `m` 个号码，开奖号码有 `k` 个落入池中：

- 全复式展开：覆盖池中所有 `base` 选组合，注数 `C(m, base)`。例如红蓝玩法 8 红全复式 = `C(8,6)=28` 注，若 6 个开奖红球都在池中，必有一注中头奖（红球全中）。
- 缩水/旋转矩阵：用更少注数保证「池中命中 k 个时至少中某一奖级」。本质是集合覆盖问题，精确最优是 NP-hard；工程上用贪心覆盖或预置 wheel 表。

多注推荐可用贪心最大覆盖：每步选择能覆盖最多「未覆盖号码对/号码组」的一注，近似比 `1 - 1/e`。它提升的是覆盖率，不是单注期望。

## 4. FEAT-002 推荐算法设计

### 4.1 特征层

对每个号码 `i` 计算并归一化：

| 特征 | 定义 | 方向 |
|---|---|---|
| `freqZ` | 窗口内频率 z 分数 | 热号策略取正，冷号策略取负 |
| `omissionRatio` | 当前遗漏 / 期望遗漏 | 遗漏策略取正 |
| `recentDelta` | 近 10 期频率 - 全窗口频率 | 趋势策略取正 |
| `posterior` | Beta 后验均值 | 稳健热度 |
| `balancePrior` | 与目标奇偶/大小/区间的匹配度 | 组合约束 |

默认归一化：min-max 或 z 分数截断到 `[-3, 3]` 后映射到 `[0,1]`，避免极端值主导。

### 4.2 打分

```text
score_i = w_freq × freqZ_i
        + w_omission × omissionRatio_i
        + w_recent × recentDelta_i
        + w_bayes × posterior_i
        + w_balance × balancePrior_i
```

策略预设权重（可配置、可展示）：

| 策略 | 权重倾向 | 说明 |
|---|---|---|
| 均衡随机 | 全 0 + 约束 | 近似均匀，保证分布均衡 |
| 热号跟随 | freqZ 高、recentDelta 中 | 跟随历史高频 |
| 冷号回补 | freqZ 低、omissionRatio 高 | 选历史低频/久未出 |
| 遗漏优先 | omissionRatio 高 | 以遗漏比为主 |
| 贝叶斯综合 | posterior + balance | 稳健收缩 + 均衡 |
| 覆盖设计 | 不按单号打分 | 在候选池上做组合覆盖 |

### 4.3 加权采样与约束

1. 用 `weight_i = exp(score_i / τ)` 做无放回加权抽样，`τ` 为温度（默认 0.5，越小越集中）。
2. 对候选做硬约束过滤：奇偶比、大小比、和值区间、跨度、连号个数、三区分布、AC 值、是否包含指定胆码。
3. 生成 `K` 个候选（默认 2000），按「特征分 + 约束偏差」排序。
4. 用 softmax 在 Top-M 中抽样，避免每次都输出同一组；多注之间做 Jaccard 去重（默认 <0.8）。
5. 同数据版本 + 同 seed 结果可复现；seed 随响应返回。

### 4.4 覆盖推荐

- 单式多注：默认 5 注，优先覆盖号码池的号码与号码对，避免 5 注高度相似。
- 复式推荐：输出号码池（如红蓝玩法 8 红 + 2 蓝），展示注数/金额/覆盖说明。
- 胆拖推荐：输出 `胆码 + 拖码 + 后区`，例如红蓝玩法 2 胆 + 6 拖 + 1 蓝；计算注数与金额。
- 所有方案必须通过规则引擎与金额上限校验。

### 4.5 回测与门槛

- 默认回测最近 50/100 期，每期用之前数据训练/打分，生成 5 注。
- 指标：各奖级命中次数、命中率、投入、回报、ROI、与随机基线的差值、95% 置信区间。
- 结论展示规则：若差值置信区间跨 0，明确写「未发现优于随机基线的证据」。
- 禁止用「某次命中」做宣传。

## 5. 方案取舍

| 方案 | 是否采用 | 原因 |
|---|---|---|
| 纯随机 | 保留为基线 | 公平、可验证 |
| 频率/冷热/遗漏 | 采用为特征与展示 | 用户可理解，计算稳定 |
| 贝叶斯平滑 | 采用 | 小样本更稳健，可给不确定性 |
| 约束采样 | 采用 | 输出更均衡，体验好 |
| 覆盖设计 | 采用（单式多注/复式推荐） | 数学上可解释的「组合优化」 |
| 马尔可夫/ML | FEAT-003 评估 | 无证据优于随机，成本高 |
| 遗传算法 | FEAT-003 可选 | 仅作为组合搜索器 |
| LLM 解释 | FEAT-003 可选 | 只做自然语言总结，不做预测依据 |
