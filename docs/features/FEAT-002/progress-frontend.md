# 前后端接入与 UI 重构进度

## 本轮任务

- AUTH-01：邀请制普通用户注册、真实登录与身份恢复；已登录用户生成邀请码，数据库存摘要，注册成功时原子核销；禁止客户端指定角色，注册和高成本分析限流。
- API-01：移除演示账号、静态数据降级和本地简化推荐；前端默认请求同源 API。
- DEPLOY-01：前端服务转发本机 API；CI 成功后部署同一版本，启动前数据库预检。
- PICK-01：单式通过后端生成完整主区与附加区；支持可选奇偶、大小、和值、三区条件。
- DESIGN-01：[UI 重构方案](ui-redesign.md) 已落盘；整体 shadcn 视觉迁移尚未实施。

实现与验证进行中；各任务独立检查，单任务超过 400 行继续拆分。最终验证和推送信息以本文件后续记录为准，不把本地测试写成线上已验收。

## 范围与限制

- 数据库及后端同机，数据库连接保持本机，不修改账号密码、认证插件或生产数据。
- 本地联调使用构造的测试数据库，通过真实 HTTP 与页面服务代理验证，不调用外部数据源。
- 注册、登录、数据和推荐错误明确展示，不自动回退模拟结果。
- CI 中的服务器部署和 GitHub Pages 是不同入口；服务器入口使用同源 API，Pages 需要独立可访问的 API 地址。
- 邀请注册涉及鉴权，需独立 AI 会话评审，并提醒第二人复核。已有数据库用户沿用，不把账号密码硬编码或提交。
- 现有部署仍采用单实例重启；失败会阻止流水线成功，但没有蓝绿切流或自动回滚，不视为零停机部署。
