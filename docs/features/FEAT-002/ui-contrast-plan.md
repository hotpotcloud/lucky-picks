# UI 暗黑配色对比度调整方案

## 1. 问题与目标

当前工作台采用石墨黑暗色界面，部分文字使用 `text-slate-500`、`text-slate-600`，或在父级使用
`opacity-60` 降低整体透明度。这些组合在深色卡片上对比度不足，实际阅读时会出现：

- 次要说明、期号、日期、图表坐标和表格表头发灰，难以辨认。
- 禁用态和占位符与背景接近，用户无法判断控件是否可用。
- 选中态只靠颜色区分，低亮度屏幕或强光环境下辨识度差。

目标是在保留暗黑科技风的前提下，把正文和关键操作提升到 WCAG 2.1 AA：

- 正文文字对比度 ≥ 4.5:1。
- 大号文字（≥ 18.66px 粗体或 ≥ 24px）对比度 ≥ 3:1。
- 输入框边框、图标、图表网格等非文字元素 ≥ 3:1。
- 选中、中奖、告警等状态不能只依赖颜色，必须同时有文字、图标或边框变化。

## 2. 现状审计

以当前深色卡片 `#11161d` 为背景计算：

| 前景色 | 用途 | 对比度 | 结论 |
|---|---|---:|---|
| `#f2f5f8` | 主文字 | 17.9:1 | 通过 |
| `#a1adbb` | `--muted-foreground` | 7.97:1 | 通过 |
| `#94a3b8` | slate-400 | 7.08:1 | 通过 |
| `#64748b` | slate-500 | 3.82:1 | 不通过 |
| `#475569` | slate-600 | 2.40:1 | 严重不足 |
| `#fb7185` | 红球号码 | 6.75:1 | 通过 |
| `#2dd4bf` | 主色/强调 | 10.5:1 | 通过 |

已确认的低对比度来源：

- 登录页、邀请面板、推荐面板、历史列表、AI 面板中的 `text-slate-500`。
- 部分父级 `opacity-60` 叠加在 `--muted-foreground` 上，等效亮度进一步下降。
- 走势图、频率图和遗漏表的坐标、表头和辅助数字。
- 输入框占位符、禁用按钮、空状态说明。

## 3. 新配色令牌

只调整暗色语义变量，不改变页面结构：

| 令牌 | 当前值 | 建议值 | 说明 |
|---|---|---|---|
| `--background` | `#090c10` | `#0a0e13` | 保持接近纯黑，减少纯黑压迫感 |
| `--foreground` | `#f2f5f8` | `#f4f7fa` | 主文字略微提亮 |
| `--card` | `#11161d` | `#141b24` | 卡片与背景拉开层次 |
| `--card-raised` | `#19212b` | `#1d2732` | 浮层、二级面板 |
| `--input` | `#10161e` | `#0f151c` | 输入框底色 |
| `--border` | `#283240` | `#5d6d82` | 边框达到非文字 3:1 |
| `--muted-foreground` | `#a1adbb` | `#c2cdda` | 次要文字提升到 11:1 |
| `--accent` | `#19212b` | `#1d2732` | 与 `--card-raised` 对齐 |
| `--primary` | `#2dd4bf` | `#2dd4bf` | 保持品牌薄荷绿 |
| `--primary-hover` | `#5eead4` | `#5eead4` | 保持 |
| `--ring` | `#2dd4bf` | `#5eead4` | 焦点环更亮 |
| `--number-red` | `#fb7185` | `#fda4af` | 红球在深色上更清晰 |
| `--number-blue` | `#60a5fa` | `#7dd3fc` | 蓝球在深色上更清晰 |
| `--banker` | `#fbbf24` | `#fcd34d` | 胆码更醒目 |

新增语义令牌：

- `--text-secondary: #c2cdda`（等价 `--muted-foreground`）。
- `--text-tertiary: #94a3b8`（仅用于辅助标签，不再使用 slate-500/600）。
- `--text-disabled: #8b98a8`（禁用态，不使用 `opacity`）。
- `--border-strong: #6b7c93`（输入框和可交互边框）。
- `--focus-ring: #5eead4`。
- `--chart-grid: #334155`（图表网格，非文字 3:1 边界）。
- `--chart-label: #94a3b8`（坐标文字）。

## 4. 组件级调整

### 4.1 全局文字

- 删除 `text-slate-500`、`text-slate-600`，统一替换为 `text-muted-foreground` 或
  `text-[color:var(--text-tertiary)]`。
- 正文默认使用 `--foreground`，说明文字使用 `--muted-foreground`。
- 禁止通过父级 `opacity` 降低文字亮度；禁用态用颜色令牌，不使用透明度。

### 4.2 输入与按钮

- 输入框边框使用 `--border-strong`，聚焦时使用 `--focus-ring` 并保留 2px ring。
- 占位符颜色 `#8b98a8`，不能低于 4.5:1。
- 禁用按钮文字 `#8b98a8`，背景 `#1a222c`，边框 `#2b3644`。
- 主按钮保持 `--primary` 背景和 `--primary-foreground` 文字。

### 4.3 号码球与选中态

- 未选中号码球：背景 `--card-raised`，文字 `--muted-foreground`。
- 选中红球：`--number-red` 背景，深色文字；选中蓝球：`--number-blue` 背景，深色文字。
- 选中态同时增加 2px 亮色描边或勾选图标，不能只靠颜色。
- 胆码增加“胆”字角标，拖码增加“拖”字角标。

### 4.4 走势图、频率图和遗漏表

- 期号列和号码表头使用 `--text-tertiary`，禁止使用半透明。
- 网格线使用 `--chart-grid`，命中格保持高对比实色。
- 频率柱状图增加数值标签，标签颜色与柱体形成对比。
- 遗漏表表头、空值、单位文字统一使用 `--text-tertiary`。
- 图表 tooltip 背景使用 `--card-raised`，文字使用 `--foreground`。

### 4.5 奖级与中奖标记

- 奖级徽标使用高对比底色 + 深色文字，并附带奖级文字，不只靠红/黄/绿区分。
- 估算奖级追加 `≈` 前缀和“估算”说明。
- 未中奖使用中性灰，不使用低透明度。

### 4.6 登录页

登录页当前有独立硬编码的 slate 色值，需要与全局令牌对齐：

- 背景 `--background`，面板 `--card`，边框 `--border`。
- 表单标签 `--text-secondary`，占位符 `--text-disabled`。
- 错误提示使用高对比 `#fecdd3` 文字和 `#7f1d1d` 背景。
- 水印保持低透明度装饰，但不能承载关键信息。

## 5. 验收方式

1. 用颜色计算脚本检查所有前景/背景组合，正文 ≥ 4.5:1，大号文字 ≥ 3:1。
2. 检查登录、选号、结果、历史、分析、推荐六个页面，确认没有 `text-slate-500/600` 残留。
3. 检查禁用态、占位符、空状态、错误提示、图表坐标和表头。
4. 在 100% 缩放下逐页阅读，确认不需要放大即可看清期号、日期、命中数和奖级。
5. 运行 `pnpm check:terms`、`pnpm lint`、`pnpm typecheck`、`pnpm build`。

## 6. 实施顺序

1. 调整 `index.css` 语义变量和全局文字颜色。
2. 替换 `text-slate-500/600` 和 `opacity` 降亮写法。
3. 调整号码球、按钮、输入框、徽标和提示组件。
4. 调整走势图、频率图、遗漏表和登录页。
5. 按验收清单逐页检查。

本方案只改视觉令牌和样式，不改业务逻辑、接口和数据结构。
