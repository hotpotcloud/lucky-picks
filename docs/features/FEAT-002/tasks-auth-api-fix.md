# 后端认证与真实 API 接入修复

用户要求：修复后端启动报错后推送；前端接入真实 API，开放注册。数据库与后端位于同一服务器。

## 实施计划

1. 后端注册与启动诊断：先测试注册、重复账号、普通用户权限、连接失败和配置缺失，再实现接口及数据库连接校验。
2. 前端真实接入：默认同源 API，移除演示登录、假管理员和静态降级；增加注册、会话恢复与错误反馈。
3. 联调与交付：本地测试数据库验证真实 HTTP 链路，运行前后端门禁，独立会话评审后提交推送。

每个子任务有效改动不超过 400 行，超出继续拆分。范围限于 auth、API 客户端、数据加载、推荐降级、数据库启动诊断及相关测试和文档；不改依赖、数据库认证、CI、构建配置或生产服务。

## 验收

- 注册创建普通用户，重复账号明确报错；新用户可登录、查询身份及访问受保护接口。
- 未配置前端 API 地址时请求同源接口，接口失败不展示模拟结果。
- 数据库密码按原始参数传递，支持特殊字符；连接错误记录不含密码的定位信息。
- 数据库使用本机地址；服务器配置错误不通过改密码或开放公网规避。
- 鉴权变更需独立 AI 评审及第二人复核，需求提出方验收。
