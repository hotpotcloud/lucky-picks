## TC-103 红蓝玩法全玩法注数与金额
- 关联需求：REQ-102、REQ-103
- 类型：正常
- 核心：是
- Given：以下方案
  - 红复式 8 红 + 1 蓝
  - 蓝复式 6 红 + 3 蓝
  - 全复式 7 红 + 2 蓝
  - 单式胆拖 2 胆 + 6 拖 + 1 蓝
  - 复式胆拖 2 胆 + 6 拖 + 3 蓝
- When：调用 `/bets/validate`
- Then：
  - 8+1：C(8,6)=28 注，56 元
  - 6+3：C(3,1)=3 注，6 元
  - 7+2：C(7,6)×C(2,1)=14 注，28 元
  - 2胆6拖+1蓝：C(6,4)=15 注，30 元
  - 2胆6拖+3蓝：15×3=45 注，90 元
- 自动化：后端单测 + API 测试

## TC-104 前后玩法全玩法注数与金额
- 关联需求：REQ-102、REQ-103
- 类型：正常
- 核心：是
- Given：
  - 前复式 6 前 + 2 后
  - 后复式 5 前 + 3 后
  - 双区复式 6 前 + 3 后
  - 前区胆拖 2 胆 + 5 拖 + 2 后
  - 后区胆拖 5 前 + 1 后胆 + 3 后拖
  - 双区胆拖 2 前胆 + 5 前拖 + 1 后胆 + 3 后拖
- When：调用 `/bets/validate`
- Then：
  - 6+2：C(6,5)=6 注，12 元
  - 5+3：C(3,2)=3 注，6 元
  - 6+3：6×3=18 注，36 元
  - 2胆5拖+2后：C(5,3)=10 注，20 元
  - 5前+1后胆3后拖：C(3,1)=3 注，6 元
  - 双区：C(5,3)×C(3,1)=10×3=30 注，60 元
- 自动化：后端单测 + API 测试

## TC-107 非法选号
- 关联需求：REQ-104
- 类型：异常
- 核心：是
- Given：
  - 空选
  - 号码超范围
  - 号码重复
  - 胆码超过上限（如红蓝玩法红胆 6 个）
  - 胆码与拖码重复
  - 拖码不足（红蓝玩法 2 胆 + 2 拖）

  - 单式模式选了 7 个红球
- When：调用 `/bets/validate`
- Then：返回 `INVALID_SELECTION` 或 `INVALID_MODE`，错误信息指出具体区域与原因
- 自动化：后端单测（参数化）
