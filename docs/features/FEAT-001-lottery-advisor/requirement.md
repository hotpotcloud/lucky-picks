# FEAT-001 一页需求：双色球 / 大乐透选号建议

- 需求提出方：项目所有者（本需求以「自主开发模式」授权 AI 完成文档、评审、开发与上线）
- 编号：FEAT-001
- 级别：标准（新特性，纯前端静态应用，不涉及鉴权、资金、数据迁移与生产密钥）
- 开发方式：垂直切片（单人全栈 + 纯前端，无后端接口）

## 背景与目标

用户希望有一个轻量的在线工具，在手机或电脑上快速生成双色球、大乐透号码建议，并能直观看到号码的奇偶、大小、和值与区间分布。完成后成功标准：

1. 打开网页即可使用，不需要注册登录。
2. 支持双色球、大乐透两种玩法的机选、复式和胆拖。
3. 生成结果合法、可复制、可保存到本地历史。
4. 通过 GitHub Pages 免费域名访问。

## 使用者与场景

- 偶尔购彩、想快速机选的普通用户。
- 想自选部分号码（胆码/复式）但懒得手算组合的彩民。
- 想检查一注号码分布是否均衡的用户。

## 功能点（可验收）

- REQ-001：支持切换彩种「双色球」「大乐透」，切换后规则、选号区与说明同步变化。
- REQ-002：机选模式可生成 1–10 注号码，支持「随机」与「均衡」两种策略；每注号码在对应区间内不重复且数量正确。
- REQ-003：复式模式允许选择超过基础数量的号码，实时展示组合注数与金额（2 元/注），并限制最大注数。
- REQ-004：胆拖模式允许选择胆码与拖码，由系统枚举所有含全部胆码的组合，实时展示注数与金额，并限制最大注数。
- REQ-005：每注结果展示号码，并给出奇偶比、大小比、和值、三区比分析。
- REQ-006：生成结果可复制到剪贴板；复制失败时给出提示。
- REQ-007：结果可保存到浏览器本地历史，历史列表支持删除单条与清空。
- REQ-008：页面固定展示免责声明：彩票为随机事件，结果仅供娱乐，不构成投注建议。
- REQ-009：页面在 360px 宽度下可用，交互控件不溢出。
- REQ-010：首次加载、生成中、空历史、非法选择均有明确状态提示。

## 不做什么

- 不接入真实历史开奖数据，不做冷热号、遗漏值等依赖历史数据的统计。
- 不做用户账号、云端同步、支付、代购或任何资金相关功能。
- 不预测中奖号码，不承诺任何中奖结果。
- 不开发后端接口与数据库（v1 为纯前端静态应用）。
- 不做多语言（界面中文，README 英文）。

## 非功能要求

- 性能：首屏在普通网络下 3 秒内可交互；单次生成 10 注耗时 < 100ms。
- 安全：无后端、无密钥、无个人信息采集；仅使用 localStorage 保存用户主动保存的号码。
- 兼容：最新版 Chrome / Edge / Safari / 移动端浏览器。
- 可用性：核心操作有 loading、空、错误状态；关键按钮有可读文案。
- 可测试：号码生成、组合计算、分析指标全部为纯函数，必须有单元测试。

## 核心用例（Given / When / Then）

- TC-001（核心）：给定双色球机选，选择 1 注并生成 → 得到 6 个不重复红球（1–33）与 1 个蓝球（1–16）。
- TC-002（核心）：给定大乐透机选，选择 3 注并生成 → 每注为 5 个不重复前区（1–35）与 2 个不重复后区（1–12）。
- TC-003（核心）：均衡策略生成双色球 10 注 → 每注奇偶比与大小比落在配置容差内，且号码合法。
- TC-004（边界）：机选注数输入 1 与 10 → 均成功；输入 0 或 11 → 前端拦截并提示。
- TC-005（核心）：双色球复式选择 7 红 + 1 蓝 → 组合注数为 C(7,6) × C(1,1) = 7 注，金额 14 元。
- TC-006（核心）：双色球胆拖选择 2 个胆码 + 6 个拖码、1 蓝 → 注数为 C(6,4) = 15 注，且每注包含全部胆码。
- TC-007（异常）：胆码数量等于基础号码数量（如双色球 6 胆）→ 提示胆码过多，禁止生成。
- TC-008（异常）：拖码数量不足（双色球 1 胆 + 2 拖）→ 提示拖码不足。
- TC-009（核心）：生成复式组合超过上限（如 1000 注）→ 拦截并提示减少号码。
- TC-010（核心）：对一注已知号码计算分析 → 奇偶比、大小比、和值、三区比与手工结果一致。
- TC-011（核心）：点击复制 → 号码按「红球 + 蓝球」格式写入剪贴板；剪贴板不可用时提示失败。
- TC-012（核心）：保存结果后刷新页面 → 历史仍存在；删除单条后对应项消失；清空后历史为空。
- TC-013（边界）：切换彩种 → 已选号码清空，规则说明与选号上限同步切换。
- TC-014（核心）：页面展示免责声明，且不出现「必中」「预测中奖」等误导性文案。
- TC-015（边界）：浏览器 localStorage 不可用或数据损坏 → 页面正常使用，仅历史功能降级并提示。
